
# Personal Portfolio 
## OASIS INFOBYTE — SIP Internship Task 
### Task Web Development & Designing — Level 1, Task 2: Personal Portfolio 
## Project Description 
This project is a responsive personal portfolio website created using HTML and CSS. It showcases personal information, skills, projects, and contact details in a clean and organized layout. 
## Features 
- Profile/Hero section
- About Me section
- Skills section
- Projects section
- Contact section
- Responsive design
- Smooth navigation between sections
- Consistent color scheme and typography
## Technologies Used
- HTML5
- CSS3
## Project Structure 
- `index.html` — Main webpage
- `style.css` — Website styling -
- `images/` — Images used in the project
